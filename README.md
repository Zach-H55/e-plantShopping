# e-plantShopping

## Paradise Nursery Shopping Application

This project is an online plant shopping application built using React and Redux Toolkit.

The application allows users to:

- Browse different categories of house plants
- View plant details including image, description, and price
- Add plants to the shopping cart
- Increase or decrease item quantities in the cart
- Remove items from the cart
- View total cart cost dynamically
- Continue shopping or proceed to checkout

## Features

- Landing Page
- Product Listing Page
- Shopping Cart Page
- Redux State Management
- Dynamic Cart Updates
- Responsive UI Design

## Technologies Used

- React
- Redux Toolkit
- React Router
- CSS
